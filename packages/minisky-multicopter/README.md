# minisky-multicopter

`minisky-multicopter` is a [MiniSky](https://github.com/open-aviation/minisky) plugin for simulating small electric multirotors.

Enable the plugin in MiniSky configuration TOML:

```toml
[plugins.multicopter]
```

For more information, visit our the multicopter guide in our documentation: <https://mode-s.org/minisky/user-guide/multicopters/>!
