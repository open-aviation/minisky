# minisky

minisky is a lightweight, headless air traffic simulation library derived from [BlueSky](https://github.com/TUDelft-CNS-ATM/bluesky).

Navigation data is distributed separately. For X-Plane 11 data, install [`minisky-xplane-navdata`](https://pypi.org/project/minisky-xplane-navdata/) alongside the core.

For more information, visit our documentation: <https://mode-s.org/minisky/>!  

Repository: <https://github.com/open-aviation/minisky>
