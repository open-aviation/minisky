# `minisky.tools`

Aeronautics and geodesy utilities, plus runtime-owned area, navigation, and
position helpers.

## Aeronautics (`aero`)

Unit-conversion constants (`ft`, `kts`, `nm`, `fpm`, ...), the ISA atmosphere, and
CAS/TAS/EAS/Mach conversions.

::: minisky.tools.aero

## Geodesy (`geo`)

Great-circle distances, bearings, and coordinate calculations.

::: minisky.tools.geo

## Shapes

Named geographic areas (boxes, circles, polygons) and graphical lines.

::: minisky.tools.shapes

::: minisky.tools.navdata.Navdatabase
