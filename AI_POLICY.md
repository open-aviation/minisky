# AI Usage Policy

We welcome using AI (e.g. LLMs) as an aid to programming.

However, contributors are responsible for understanding any code/documentation submitted to this repository.

When opening an issue or pull request, describe it in your own words. If you wish to include context from an interaction with AI, put them under an [HTML `<details>` block](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details).

If you wish to persist any useful information for agents (for example, `AGENTS.md`, `SKILL.md`), put them under `docs/.agents`. Do note that any file placed under there are assumed to be entirely AI-generated and not intended for humans to read.

All content aside from `docs/.agents` will be read and maintained by humans.
